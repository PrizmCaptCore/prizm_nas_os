# PRIZM NAS OS 로드맵

프로젝트의 방향성과 계획된 기능들입니다.

## 버전 0.1.0 (현재) ✅

**목표**: 기본 NAS 기능 + 네트워크 기능 통합

- [x] Arch Linux 기반 빌드 시스템
- [x] 파일 공유 (SMB/NFS)
- [x] 기본 스토리지 관리 (Btrfs, LVM, mdadm)
- [x] Docker 컨테이너 지원
- [x] Cockpit 웹 관리 UI
- [x] 네트워크 기능 (VLAN, VPN, 라우팅)
- [x] 관리 도구 (nas-setup, nas-status, nas-network)

## 버전 0.2.0 (다음 릴리스) 🚧

**목표**: 사용성 개선 및 안정화

### 우선순위 높음
- [ ] **웹 기반 설치 마법사**
  - 브라우저에서 초기 설정 가능
  - 네트워크/스토리지/서비스 설정 통합
  - 진행 상황 시각화

- [ ] **ZFS 네이티브 통합**
  - ISO에 ZFS 드라이버 포함
  - 설치 시 ZFS 선택 옵션
  - ZFS 풀 관리 GUI

- [ ] **자동 백업 시스템**
  - 스케줄 기반 백업
  - 다중 백업 타겟 (로컬, NFS, S3)
  - 백업 검증 및 복구 테스트

### 우선순위 중간
- [ ] **모니터링 및 알림**
  - 이메일/Telegram/Discord 알림
  - 디스크 건강 상태 알림
  - 시스템 리소스 임계값 알림

- [ ] **플러그인 시스템**
  - 커뮤니티 플러그인 지원
  - 앱 스토어 형태의 UI
  - 원클릭 설치

- [ ] **다국어 지원**
  - 영어, 한국어 우선
  - 커뮤니티 번역 기여 시스템

### 우선순위 낮음
- [ ] **성능 최적화**
  - 네트워크 스택 튜닝
  - 스토리지 I/O 최적화
  - 메모리 사용량 최적화
